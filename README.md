# Supertest: ejercicios de API de vehículos

Actividad de la Universidad Luterana Salvadoreña.
Cinco ejercicios para probar una API hecha con Express usando **Supertest**.

## Requisitos
- Node.js (versión LTS) y npm

## Instalación
```bash
npm install
```

## Ejecutar las pruebas
```bash
npm test
```

## Ver la API en el navegador (opcional)
```bash
npm start
```
Luego abre http://localhost:3000/vehiculos

## Documentación oficial
- Supertest: https://github.com/ladjs/supertest
- Express: https://expressjs.com
